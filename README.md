# 岭南小富翁

南国商道，岭南风情，由你来开拓

一款基于 Unity 开发的岭南文化 3D 回合制大富翁类模拟经营游戏，融合岭南建筑文化与商道精神，讲述玩家在岭南古城中经营商铺、积累财富、成为一代商贾的故事。

## ? 游戏介绍

《岭南小富翁》是一款 3D 回合制大富翁类模拟经营游戏，主打策略经营、资产积累与岭南文化体验。

- **游戏类型**：回合制 / 模拟经营 / 策略

- **开发引擎**：Unity（URP 渲染管线）

- **单局时长**：30–60 分钟

- **核心主题**：融合岭南建筑文化，以商业经营为核心玩法

- **目标玩家**：喜欢策略规划、模拟经营、国风题材的休闲玩家

## ? 游戏特色

- **岭南建筑文化**：还原茶铺、酒楼、钱庄、古玩店等岭南特色商铺

- **8 状态回合制 FSM**：完整的回合制闭环，流畅的游戏流程

- **复合经济系统**：5 种建筑类型 × 4 种收益触发机制，策略性强

- **灵活 Buff/Debuff 框架**：3 种时效类型 × 6 种效果类型，玩法多变

- **ScriptableObject 数据驱动**：策划零代码配置，开发效率高

- **3D 视觉体验**：URP 天空盒、昼夜光照、下雨粒子特效

- **物理骰子投掷**：真实物理模拟的骰子掷骰体验

- **道具与卡牌系统**：丰富的随机事件与奇遇机制

## ? 核心玩法

1. **掷骰移动与购地**：物理骰子决定步数，购买地产成为业主

2. **建造与升级**：在地块上建造岭南特色商铺，升级获取更高收益

3. **多维度收益结算**：租金、骰子奖励、自动收益、房产增值等多种收益方式

4. **Buff/Debuff 系统**：移速加成、骰子增益、收入倍率等效果叠加

5. **随机事件与道具**：奇遇地块获得卡牌，负面地块面临挑战

6. **压力值与经济模型**：贷款、税收、压力值多维经济系统

## ?? 岭南建筑特色

游戏中还原了多种岭南特色商铺建筑：

- **茶铺**：功夫茶文化，提供 Buff 增益
- **酒楼**：餐饮经营，稳定收益
- **钱庄**：金融服务，关联收益
- **当铺**：典当业务，骰子触发收益
- **古玩店**：古玩交易，房产增值
- **拍卖行**：拍卖业务，高风险高回报
- **小摊贩**：小本经营，入门友好
- **交易处**：资产交易，灵活变现

## ? 地块系统

| 地块类型 | 说明 |
|---------|------|
| 起点 | 每回合发工资，恢复状态 |
| 事件地块 | 随机事件，2-3 个选项决策 |
| 奇遇地块 | 直接获得金币 + 稀有卡牌 |
| 负面地块 | 扣除金币，需要应对挑战 |
| 普通地块 | 可购买建造商铺 |

## ?? 技术亮点

- **8 状态 FSM 框架**：实现等待→回合→掷骰→移动→落地处理→购地/选建筑/放建筑的完整回合制闭环

- **ScriptableObject 数据驱动架构**：建筑数据、事件数据、Buff 数据全部 ScriptableObject 配置，策划零代码开发

- **复合经济系统**：
  - 5 种建筑功能类型：收益型 / Buff 型 / 混合型 / 骰子触发型 / 增值型
  - 4 种收益触发方式：关联收益 / 骰子匹配 / 自动收益 / 增值卖出

- **Buff/Debuff 框架**：支持时间型 / 回合型 / 永久型 3 种时效机制，涵盖移速加成、骰子增益、收入倍率、负面免疫等 6 种效果

- **URP 渲染管线**：
  - 程序化天空盒与昼夜光照
  - 下雨粒子 + 涟漪特效
  - 物理骰子投掷动画
  - 角色抛物线跳跃移动

- **系统架构**：模块化设计，Buff 系统、建筑系统、事件系统、道具系统独立解耦

## ? 下载与游玩（Windows）

游戏可执行包已发布在本仓库 **Releases**，下载即可直接游玩：

1. 前往右侧 [Releases](https://github.com/your-repo/LingnanTycoon/releases) 下载最新版压缩包

2. 解压到**纯英文路径**（不要有中文、空格、特殊符号）

3. 打开解压文件夹，双击 `LingnanTycoon.exe` 运行游戏

### ?? 重要注意

- 仅支持 **Windows 64 位系统**

- 必须保持 `exe`、`xxx_Data` 文件夹、`UnityPlayer.dll` 在同一目录，不可拆分移动

- 游戏进度自动存档，重启可继续游玩

## ?? 技术栈

- **UI 框架**：UGUI + TextMeshPro
